# ЗАБЬЁМСЯ

Промосайт платформы челленджей и LIVE-дуэлей «ЗАБЬЁМСЯ».

- Приложение: <https://zabyemsya.ru/>
- Лендинг: <https://zabyemsya.online/>

## Локальный запуск

```bash
npm ci
npm run dev
```

## Статическая сборка

```bash
npm run build:pages
```

GitHub Actions публикует содержимое `dist-pages` в GitHub Pages после каждого обновления ветки `main`. Инструкция по настройке находится в [GITHUB_PAGES.md](GITHUB_PAGES.md).
